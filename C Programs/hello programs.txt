How It Works

#include <stdio.h>
Includes the standard input-output library.
This contains the printf function.

int main()
The starting point of the program.
Every C program must have one.

printf("Hello, World!\n");
Prints the text to the screen.
\n moves the cursor to a new line.
The semicolon ; ends the statement.

return 0;
Signals successful execution to the system.
